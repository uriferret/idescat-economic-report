# Seguretat

Aquest repositori conté codi d'anàlisi i estadístiques públiques de l'Idescat. No gestiona dades personals ni credencials.

## Com informar d'un problema

Si hi trobes un problema de seguretat (per exemple, una dependència vulnerable o un fitxer que no hauria de ser públic), no obris una incidència pública. Fes servir **Report a vulnerability** a la pestanya [Security](https://github.com/uriferret/idescat-economic-report/security) del repositori i et respondré tan aviat com pugui.

Només es manté la versió més recent de la branca `main`.

---

## Security

This repository contains analysis code and public statistics from Idescat. It handles no personal data or credentials.

If you find a security issue (for example, a vulnerable dependency or a file that should not be public), please do not open a public issue. Use **Report a vulnerability** in the repository's [Security](https://github.com/uriferret/idescat-economic-report/security) tab and I will reply as soon as I can.

Only the latest version of the `main` branch is maintained.
